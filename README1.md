About the Project

A full-stack web application developed using modern web technologies. It includes a frontend for user interaction and a backend for handling application logic and APIs.

Technologies Used

Frontend: React.js, HTML, CSS, JavaScript

Backend: Node.js, Express.js

Database: MongoDB

Project Structure

frontend/ – User interface and frontend functionality.

backend/ – Server-side logic and API development.

How to Run

Backend

cd backend
npm install
npm start

Frontend

cd frontend
npm install
npm run dev

Features:
User-friendly interface
Backend API integration
Database connectivity
